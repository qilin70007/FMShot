# FMShot 轻量版上线说明

网站：https://fmshot.qlxiao.chatgpt.site

2026-10-05 已通过 ChatGPT Work Sites 发布，当前仅站点所有者可访问。用创建站点的 Work 账号登录即可。轻量版源码由 Sites 的源代码仓库保存并管理；本 GitHub 仓库继续保存 AIHOT 改造后的完整版。

## 现在直接可用

- 8 个公开信源：EASA 新闻、审定规范、拟议修订；Universal Avionics 产品公告和技术博客；Aviation Today；EUROCONTROL；Federal Register。
- 原文标题、发布时间、来源链接、关键词分类、搜索与信源筛选。
- 单独筛选与 FMS 直接相关的动态，区分航电及适航关联资讯。
- 收藏保存在当前浏览器本地，不与其他设备同步。

打开页面时读取公开信源，服务实例内缓存约 15 分钟；没有关闭页面后运行的定时采集或模型任务。点击“刷新资讯”重新检查当前可用数据，缓存期内可能仍返回同一批结果。

## 简化的运行方式

使用当前 Work Sites 托管，不要求另购服务器，不启动 PostgreSQL、Docker 或付费模型，不要求 API Key。轻量版未启用 AI 热度评分、自动翻译或日报／周报／月报。栏目标题为行业动态，按发布时间排序，不虚构热度分数。

请求失败的信源会显示连接状态；有已核验资料时展示 2026-10-05 核验快照，并在每条旧资料旁标明“快照”。未发现匹配条目时显示 0 条，不代表采集失败。关键词分类尚未经过人工审核，原文适用条件、版本和公告阶段需阅读来源确认。

## 验证

上线前完成 TypeScript 检查、4 项解析与筛选检查及 Worker 构建；Sites 私有发布返回 succeeded。实时试抓至少接通 5 个信源，获取 35 条匹配动态、5 条 FMS 直接相关动态；这只是该次检查结果，后续数量会随信源和连接状态变化。

当前环境未提供 Sites 支持的浏览器验证能力，因此未做浏览器截图检查。

## 后续维护

修改网站时使用同一个 Sites 项目，保留既有私有访问范围和 .openai/hosting.json 的 project_id，通过 Sites 更新并发布。若将来需要所有人可访问，再明确改变网站的访问范围。
